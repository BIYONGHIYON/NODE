# 🚀 [NODE]

두 명의 우주인이 로프 하나에 의지해 다이내믹한 중력을 극복하고 우주를 탐험하는 2.5D 코옵 플랫포머 게임입니다.

![Game Screenshot/GIF](여기에_스크린샷이나_움짤_링크를_넣으세요)

---

## 🎮 게임 특징 (Key Features)

* **다이내믹한 중력 시스템:** 고중력 목성과 떠다니는 무중력 토성 등, 각 행성마다 완전히 달라지는 물리 엔진을 경험하세요.
* **로프 액션:** 파트너나 지형에 로프를 걸고 스윙하여 장애물을 넘고, 구성된 퍼즐을 풀어보세요.
* **물리 기반 기믹:** 밀고 당길 수 있는 운석과 지형지물을 활용해 데스존(Death Zone)을 돌파해야 합니다.
* **독립적 체크포인트 & 협동 클리어:** 각자 험난한 지형을 돌파해 체크포인트를 찍고, 맵 곳곳에 흩어진 연료통을 함께 모아야 다음 행성으로 도약할 수 있습니다.

---

## 🕹️ 조작 방법 (Controls)

| 액션 | Player 1 | Player 2 |
| :--- | :--- | :--- |
| **이동** | W, A, S, D | Up, Left, Down, Right Arrow |
| **로프 발사/해제** | (F) | (Ctr or Alt/Opt) |
| **메뉴** | ESC | ESC |

---

## 🛠️ 기술 스택 (Tech Stack)

* **Engine:** Unity (사용하신 유니티 버전 입력)
* **Language:** C#
* **Platform:** PC (Windows / MacOS)

---

## ⚙️ 설치 및 실행 방법 (How to Play)

1. 우측 상단의 `Code` 버튼을 눌러 ZIP 파일로 다운로드하거나 저장소를 클론합니다.
2. 압축을 풀고 `Build` 폴더 내의 `[실행파일이름].exe`를 실행합니다.
3. 협력할 친구와 함께 플레이하세요!
