# 🚀 [NODE]

두 명의 우주인이 로프에 의지해 다이내믹한 중력을 극복하고 우주를 탐험하는 2.5D Local Co-op 플랫포머 게임

![Game Screenshot/GIF](여기에_스크린샷이나_움짤_링크를_넣으세요)

---

## 🎮 게임 특징 (Key Features)

* **다이내믹한 중력 시스템:** 고중력 목성과 떠다니는 무중력 토성 등, 각 행성마다 달라지는 물리를 경험하세요.
* **로프 액션:** 파트너나 지형에 로프를 걸고 스윙하여 장애물을 넘고, 구성된 퍼즐을 풀어보세요.
* **물리 기반 기믹:** 밀고 당길 수 있는 운석과 지형지물을 활용해 데스존(Death Zone)을 돌파하세요.
* **체크포인트 & 협동 클리어:** 험난한 지형을 돌파해 체크포인트를 찍고, 맵 곳곳에 흩어진 연료통을 모아야 다음 행성으로 이동할 수 있습니다.

## 🕹️ 조작 방법 (Controls)

| 액션 | Player 1 | Player 2 |
| :--- | :--- | :--- |
| **이동** | W, A, S, D | Up, Left, Down, Right Arrow |
| **로프 발사/해제** | (F) | (Ctr or Alt/Opt) |
| **메뉴** | ESC | ESC |
