# 🚀 [NODE]

두 우주비행사가 로프를 이용해 우주를 탐험하는 2.5D Local Co-op 플랫포머 게임

https://github.com/user-attachments/assets/5ab698a2-caba-4773-ac90-e37cc6a2ec21

---

## 🎮 게임 특징 (Key Features)

* **다이나믹한 중력 시스템:** 고중력 목성과 떠다니는 무중력 토성 등, 각 행성마다 달라지는 중력을 경험하세요.
* **로프 액션:** 파트너나 지형에 로프를 걸고 스윙하여 장애물을 넘고, 구성된 퍼즐을 풀어보세요.
* **퍼즐 요소:** 밀고 당길 수 있는 운석과 지형지물 등을 활용해 연료를 찾아야 합니다.
* **체크포인트 & 협동 클리어:** 두 플레이어는 험난한 지형을 풀어나가며 체크포인트를 찍고, 맵 곳곳에 흩어진 연료통을 모아야 다음 행성으로 이동할 수 있습니다.

---

## 🕹️ 조작 방법 (Controls)

| 액션 | Player 1 | Player 2 |
| :--- | :--- | :--- |
| **이동** | W, A, S, D | Up, Left, Down, Right Arrow |
| **로프 발사/해제** | (F) | (Ctr or Alt/Opt) |
| **메뉴** | ESC | ESC |

---

## 🛠️ 기술 스택 (Tech Stack)

* **Engine:** Unity (2022)
* **Language:** C#
* **Platform:** PC (Windows / MacOS)

---

## ⚙️ 설치 및 실행 방법 (How to Play)

1. [최신 Release 페이지로 이동](https://github.com/BIYONGHIYON/NODE/releases/latest)한 후, 본인의 운영체제에 맞는 설치 파일을 다운로드합니다.
2. Windows의 경우 `NODE.exe`파일을 실행하여 설치합니다.
3. Mac의 경우 `NODE_Mac.dmg`파일을 실행하여 설치합니다.
4. 친구와 함께 플레이하세요!
